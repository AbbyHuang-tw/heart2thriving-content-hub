## 更新紀錄規則

自 2026-11-19 起，三站的**所有內容更新**都記進 [CHANGELOG.md](CHANGELOG.md)，並推送到這個 repo。要記的更新包括：

- 新文章上線
- 舊文修訂
- 頁面改版
- 系列規劃變動
- 站台結構調整

如果某次更新改變了 docs 裡的數字或狀態，docs 也要同步更新。
