# 04 跨站整合與路線圖

> 三站各自有完整的內容樹，但站與站之間的互連還沒有系統性的規劃。這份文件列出把三站接成一個官方主站體系要做的事。
> 盤點日期：2026-11-19

圖例：✅ 完成　🟡 進行中　⬜ 規劃中

## 一、內容原則（三站共通）

1. **判斷優先於操作**：寫給要做決策、要驗收的人，講目的、效果與極限。
2. **查證先於下筆**：數字要附出處；法規死線、價格、原廠動態都必須能追到一手來源。
3. **資料是內容的根**：軟體選的文章核心必須是站內資料（矩陣、價格、聲量），不量產空洞文章。
4. **Cluster 結構**：每個主題都是 pillar 加 spoke，篇與篇雙向內鏈；跨 cluster 靠「定律」搭橋。
5. **不自承寫錯**：修訂直接改正，必要時標註更新日期。讀者不知道先前寫了什麼，自承錯誤只會折損可信度。
