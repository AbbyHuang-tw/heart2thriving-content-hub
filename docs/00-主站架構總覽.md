# 00 主站架構總覽

> 把心連興、erpmaster、軟體選三個站視為**一個官方主站體系**來企劃內容。
> 盤點日期：2026-11-19

## 一、三站分工

| 層 | 站台 | 回答讀者的問題 | 主要讀者 |
|---|---|---|---|
| 品牌層（官方主站） | [心連興 heart2thriving.com](https://heart2thriving.com/) | 「誰能幫我？」：服務、案例、團隊、課程，加上行銷與 SEO 判斷力 | 要做行銷、系統決策的企業主與主管 |
| 專業知識層 | [ERP Master erpmaster.tw](https://erpmaster.tw/) | 「ERP 和內控該怎麼想、怎麼做？」 | 準 IPO 公司、財會、稽核、IT 主管 |
| 工具層 | [軟體選 softpick.com.tw](https://softpick.com.tw/) | 「該買哪一套、多少錢、別人怎麼說？」 | 正在選購軟體的中小企業 |

一句話：**心連興講「誰來做」，erpmaster 講「怎麼想」，軟體選講「買哪個」。**

## 三、讀者旅程與導流

```
     認知問題                    建立方法                     做出選擇                找人協助
┌──────────────┐        ┌──────────────┐          ┌──────────────┐      ┌──────────────┐
│ 心連興文章    │  ───▶  │ erpmaster    │  ───▶    │ 軟體選       │ ───▶ │ 心連興服務頁  │
│ 行銷素養／SEO │        │ 選型／內控    │          │ 比較／行情    │      │ 健檢／顧問    │
└──────────────┘        └──────────────┘          └──────────────┘      └──────────────┘
```

- **行銷讀者**：心連興文章 → 數位廣告健檢表單／SEO 服務
- **ERP 讀者**：erpmaster 文章 → 軟體選 ERP 比較與行情 → 心連興 ERP 選型、Pre-IPO 服務
- **軟體買家**：軟體選指南 → 需要導入方法論時回連 erpmaster；需要顧問時到心連興
